Projets

Labo réseau trois paliers — labo.local

VirtualBox · Ubuntu Server · Windows Server 2022 · Samba · Active Directory · Kerberos
  • Palier 1 — VM Ubuntu Server avec adressage IP statique configuré via netplan
  • Palier 2 — Serveur de fichiers Samba avec accès inter-VM
  • Palier 3 — Contrôleur de domaine Windows Server 2022 (AD DS, domaine labo.local), VMs Ubuntu jointes au domaine via realmd/sssd avec authentification Kerberos
